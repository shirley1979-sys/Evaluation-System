# EverEx 2026 다면평가 시스템

EverEx 사내 360도 다면평가 웹 애플리케이션입니다.
단일 HTML 파일로 구성되어 별도 서버 없이 브라우저에서 바로 실행 가능합니다.

## 주요 기능

| 기능 | 설명 |
|------|------|
| 직원 로그인 | 이메일 + 주민번호 앞 6자리 |
| 동료 추천 | 팀원·협업부서에서 7명 추천 → HR 확정 |
| 1~5 척도 평가 | 공통·팀장하향·동료·상향 평가 |
| 셀프 평가 | 서술형 또는 프로젝트별 자기평가 |
| 개인 리포트 | 점수 카드 + 역량 레이더 차트 + 익명 코멘트 |
| IDP | 개인 개발 계획 작성 (평가 결과 연동) |
| HR 대시보드 | 전체 진행률 · 동료 확정 · 점수 캘리브레이션 |
| 모바일 지원 | 반응형 UI (768px 이하) |

## 접속 방법

`index.html` 파일을 브라우저에서 열거나,
GitHub Pages / 정적 호스팅에 업로드하면 바로 사용 가능합니다.

## 데모 계정

| 역할 | 로그인 방법 |
|------|------------|
| 직원 (이서연) | 데모 버튼 클릭 |
| 팀장 (김민준) | 데모 버튼 클릭 |
| HR 관리자 | 데모 버튼 클릭 |
| 슈퍼관리자 | admin / Everex2026! |

## 점수 산정 공식

- **평가 항목 점수** = 공통 문항 평균 × 0.7 + 유형별 문항 평균 × 0.3
- **종합 점수** = 팀장평가 × 0.50 + 동료평가 × 0.35 + 상향평가 × 0.15

## 익명 보호 규칙

- 동료 코멘트: 응답자 **2명 이상** 시 공개
- 상향 코멘트: 응답자 **3명 이상** 시 공개
- HR 관리자는 규칙 무관 전체 열람 가능

## 기술 스택

- 순수 HTML/CSS/JavaScript (No Framework)
- localStorage 기반 데이터 저장
- SheetJS (Excel 파일 파싱)
- Google Fonts (Pretendard)
